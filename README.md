# Montana — фан-сайт

Третий проект в портфолио. Сделал страницу про легендарные электронные часы Montana — те самые, с мелодиями, о которых мечтали школьники в конце 80-х.

**Посмотреть:** https://azer1xxx1337.github.io/Montana/

## Что тут есть

- 3D-модель часов, которая поворачивается и приближается, пока листаешь разделы: экран, надпись с мелодиями, боковые кнопки, задняя крышка с орлом, браслет. На компе можно покрутить мышкой.
- На экране модели идут секунды — это анимация из самой модели.
- Живые LCD-часы на первом экране, собранные из семисегментных цифр на SVG: текущее время, день недели, AM/PM.
- Плеер с тремя мелодиями («К Элизе», «Турецкий марш», «Jingle Bells»). Звук синтезируется прямо в браузере квадратной волной, чтобы звучало как пищалка в часах.
- Разделы про историю, кнопки, цену и то, сколько такие часы стоят сейчас.
- Адаптив под телефон.

## Как сделано

HTML, CSS и JavaScript без фреймворков. 3D — Three.js (r128) и GLTFLoader. Модель в оригинале весила 25 МБ, я пережал текстуры до 14 МБ и разбил файл на три части (`model-1.js`, `model-2.js`, `model-3.js`), они склеиваются при загрузке.

## Запустить у себя

Открыть `index.html` в браузере (все файлы должны лежать в одной папке).
